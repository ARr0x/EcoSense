# Journal de bord

## Vendredi 30 mai 2026

### Travaux réalisés
- Prise en main du sujet.
- Session de brainstorming en groupe sur l'architecture cible.
- Réalisation d'un whiteboard pour formaliser les idées.
- Création du dépôt Git du projet.
- Étude d'une première solution basée sur AWS IoT Core.
- Conception de l'architecture V1.
- Répartition des tâches pour la séance suivante.

---

## Lundi 1 juin 2026

### Travaux réalisés
- Création d'une première version de la solution directement dans la console AWS afin de valider les choix techniques.
- Simplification de l'architecture grâce à l'intégration d'Amazon Data Firehose.
- Réflexion sur la haute disponibilité multi-zones.
- Ajout de Route 53 avec Hosted Zones et Health Checks pour le basculement automatique.
- Conception de l'architecture V2.
- Début du développement de l'infrastructure en Python avec AWS CDK.
